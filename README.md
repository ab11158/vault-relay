# Vault Relay 7.15

Vault Relay 通过同一群组和百度网盘同步 Obsidian 知识库。Windows、Android、iPhone 和 iPad 可使用同一插件，正式写入前需要审核确认。

7.15 是真机测试版。下载后点「刷新」、④或⑤，轻量扫描后直接进入审核。要先勾选包，可打开「手动查找／选择 ZIP」。审核页和扫描结果页均可全盘扫描或添加外部 ZIP / 回执。经核验的新包可以登记对端设备资料，并更新圈③的群组下载目录。同路径冲突支持查看原文、导入、备份导入和取消导入。
