# Vault Relay 7.4.1

Vault Relay 通过共享群组和百度网盘同步 Obsidian 知识库。Windows、Android、iOS 和 iPadOS 使用同一插件，导入笔记前需要审核确认。

7.4.1 是真机测试版。Windows 可从本机下载目录扫描或手动选择百度网盘批量 ZIP。各设备也可把批量 ZIP 放入 Dbox，集中审核校验通过的原始增量包。每台设备第一次启用时生成自己的设备 ID。增量包会带上设备 ID 和简称，在「设备管理」中确认信任后，即可按简称选择隐私笔记的开放对象。

从 [GitHub 7.4.1 发布页](https://github.com/ab11158/vault-relay/releases/tag/7.4.1) 获取安装文件。建议在各设备分别新建空白测试库，再安装 7.4.1。使用 BRAT 安装时可指定版本 7.4.1。
