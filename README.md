# Vault Relay 8.5

Vault Relay 通过同一群组和百度网盘同步 Obsidian 知识库。Windows、Android、iPhone 和 iPad 可使用同一插件，正式写入前需要审核确认。

8.5 提供完整的免费功能。通过百度网盘网页或 App 传输增量 ZIP，省去自建同步服务器的费用，无需申请百度网盘 API 或开通百度网盘会员。 加入群组前后使用同一套扫描规则。未入组时可以选择一个普通增量首包，读取群组 ID 并确认加入后继续审核。下载后点「刷新」、④或⑤，轻量扫描后直接进入审核。要先勾选包，可打开「手动查找／选择 ZIP」。审核页和扫描结果页均可全盘扫描或添加外部 ZIP / 回执。经核验的新包可以登记对端设备资料，按群组规则更新圈③下载目录，并补填本机空白的圈②上传目录。同路径冲突支持查看原文、导入、备份导入和取消导入。
